feat: dsh-llm-retry-boost — boost model-request retries to 50/always

A DeepSeek Harness Host plugin (TypeScript) that installs an additional
listener on the agent/request-error recovery waterfall. Defaults to
always-mode (retry until success / cancel / dispose); normal-mode budget
defaults to 50 instead of the built-in 5. Keeps an in-memory per-step retry
count and registers no session projection, so it coexists safely with the
built-in dsh-llm-retry. lib/ is committed so the bundle installs without a
build step.

For unstable / rate-limited remote LLM endpoints. License follows the
Apache-2.0 LICENSE in this repo.
